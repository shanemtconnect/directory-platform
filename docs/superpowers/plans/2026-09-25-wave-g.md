## Global constraints

- No third-party ad networks; PayPal only (Stripe forbidden). Prices in `siteConfig` never hard-coded.
- Never remove existing features or copy; the requester-verification step CHANGES quote delivery timing
  (recipients are emailed after the click) — this is the one behavioural change Shane approved.
- Every advertised href has a static route file (`navigation.test.ts`); flag off = page 404 + no nav entry.
- Public writes: honeypot → validate → `limitPublicWrite` → Turnstile. Owner/admin writes: audit row.
- New config sections are typed in `config/types.ts`, defaulted in `site.config.ts`, emitted by
  `lib/clone/write-config.ts`, and validated in `config/validate.ts` (flag dependencies too).
- Reserved slugs: add `leads`, `neighbourhoods` to `lib/routing/slugify.ts` RESERVED_SLUGS.
- No new heavy deps. No phone library: a country-aware normaliser lives in `lib/geo/phone.ts` (Task 56).

## Decisions (controller, no questions asked)

| # | Decision |
|---|----------|
| D1 | Neighbourhoods = `areas` rows with a new nullable `city_id`; niche-national only; page at `/<city>/<area>`; indexable only with ≥ `geo.neighbourhoods.minListings` (default 5) published listings, else `noindex`. Listings join a neighbourhood by nearest centroid within `radiusKm` (import job), never by hand-typed text. |
| D2 | Verified-only is a query param `verified=1` on `/search` and every pillar grid, no flag. |
| D3 | Saved searches require a signed-in account (Better Auth); max 10 per user; daily or weekly digest; only NEW listings/jobs since the last digest; one-click unsubscribe with a new token claim `{ savedSearchId }`. |
| D4 | URL importer reads OpenGraph + JSON-LD (`LocalBusiness`/`Organization`) from any public page through the SSRF-safe fetcher; Facebook/Google usually block it and the form says so honestly. Labelled "Import from your website". |
| D5 | A lead is created only when a verified quote request reaches NO paid-tier local listing, or comes from a capture box (home/rails) with no listing target, or is an enquiry to an unclaimed listing with no email. Paid locals keep their free quotes exactly as today. |
| D6 | Requester must click a verification link before anyone is emailed or a lead is sold. Unverified requests expire after 48 h. |
| D7 | Prepaid credit ledger per user; top-ups via PayPal Orders in fixed packs (`leads.packs`, default 50/100/300 currency units). Credit is never cashed out except by admin adjustment. |
| D8 | Allocation on verification: standing orders covering the lead's town (city, its region, or national) and category, balance ≥ price, ranked price desc → created asc. One buyer per lead. No match → board at `leads.floor` (default 25). |
| D9 | Board price halves after `halfPriceAfterDays` (7) and the lead is deleted after `deleteAfterDays` (30). |
| D10 | Refunds are credit only, reported within `refundWindowDays` (7), admin-approved from `/admin/leads`; approval blocklists the lead's phone + email for 12 months; a buyer above 33 % refund rate is flagged (badge in admin), not auto-blocked. Reasons: `dead_phone`, `wrong_person`, `bounced`, `spam`, `never_asked`, `wrong_area`. No-refund reasons are printed on the board page. |
| D11 | Rejection rules before sale: phone must normalise for the site's country and not be a premium/test range; email domain not on the in-repo disposable list; phone/email not on the blocklist; same phone or email within 30 days = duplicate (not sold, requester told). |
